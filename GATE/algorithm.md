# Algorithm
Finite set of steps to solve a problem is called an Algorithm.

## Asymtotic Analysis

### Lifecycle Steps

- Problem definition
- Requirement
- Logic (Design)
- Development (sudo code)
- Validation
- Analysis
- Implementation
- Testing and debugging

### Need for Analysis

**Reasons for analysis:**
Performance Comparision against performance metrics like: Time & Space

### Methodology of Analysis

#### Aposteriori Analysis
Platform dependent analysis

**Advantages:**
1. Exact value of time and space complexity

**Disadvantages:**
1. System dependent
2. Hard to carry-out

#### Apriori Analysis

Platform independent analysis, generally based on step count.

**Advantages:**
1. Always gives same values

**Disadvantages:**
1. Approximate value of time and space complexity
