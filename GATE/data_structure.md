- Linear Data Structure
Every element can have atmost 2 neighbours: array, stack, queue

- Non-linear Data Structure
Elements can have more than 2 neighbours: tree, graphs

# Linked List
The pointer to Linked List points to a node called head, each node has a nullable "next" pointer which points to the address of next node.

### Types
1. Singly Linked: Only have pointer to next item
2. Doubly Linked: Has pointer to prev element too
3. Circular Linked: Last pointer points to head
4. Doubly Circular: Doubly linked with last pointer pointing to head.

### Searching
Depends on the size of the linked-list.
